# Задача
Собрать прототип на основе готовых макетов для проверки сценария подключения уже одобренного кредита.

# Сценарий
- У пользователя в личном кабинете появляется одобренное предложение кредита
- Пользователь кликает на предложение и попадает на промо-страницу
- На промо он:
  - знакомится с условиями
  - выбирает сумму и срок кредита через калькулятор
- После выбора параметров переходит на следующий шаг
- На следующем шаге:
  - проверяет условия
  - может посмотреть график платежей
  - подписывает документы
- После нажатия «Подписать и получить деньги»:
  - открывается модальное окно для ввода СМС-кода
  - после ввода кода — модальное окно успеха

# На что обратить внимание в прототипе
- Пользователь замечает и считывает основную информацию на промо
- Пользователь понимает, что можно менять параметры в калькуляторе
- Пользователь осознаёт, что именно он выбирает (сумму, срок)
- Пользователь понимает, что будет следующий шаг перед получением денег (подписание)
- Пользователь понимает, что происходит после нажатия «Подписать и получить деньги»
- Пользователь корректно проходит сценарий на мобильном экране
- Калькулятор и ключевая информация остаются доступными и заметными на малых экранах
- Не теряются важные элементы (например, кнопка продолжения, информация о комиссии)

# Отдельные вопросы для проверки
- Понимает ли пользователь, что расчёт в калькуляторе примерный
- Пользователь понимает, что предложение предварительно одобрено и есть финальная проверка
- Понимает ли, из чего состоит платёж (тело + комиссия)
- Понимает ли, как и когда начисляется комиссия
- Достаточно ли информации для принятия решения

# Ограничения и нюансы
- Деньги поступают не мгновенно (есть задержка)
- Прототип должен учитывать адаптив для мобильных устройств
- Точные условия финализируются после подписания документов
- Перевод и снятие средств — в рамках тарифного плана

# Состав прототипа
- Промо-страница с калькулятором
- Страница с итоговыми условиями и документами
- Просмотр графика платежей (из второго шага)
- Модальное окно ввода СМС-кода
- Модальное окно успешного подключения
